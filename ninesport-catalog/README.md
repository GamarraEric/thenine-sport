# The Nine Sport — Sistema de pedidos

Catálogo online y panel de gestión para el local.

## Sitios

| Uso | Archivo |
|-----|---------|
| Catálogo (clientes) | `index.html` |
| Panel (local) | `admin.html` |

## Panel

1. **Pedidos** — Recibir, tomar, avisar al cliente por WhatsApp, preparar y entregar  
2. **Stock** — Alta y edición de productos (foto, precio, talles, proveedor)  
3. **Clientes** — Contacto, historial y totales  

## Configuración

Editar `js/config.js`:

- URL y clave del proyecto  
- Email del administrador  
- Número de WhatsApp del local  

## Publicación

Publicar la carpeta del proyecto en el hosting configurado.  
Panel: `…/admin.html`

## Panel en el celular (instalar)

El **panel** (`admin.html`) se puede instalar como aplicación:

- **Android (Chrome):** menú ⋮ → *Instalar aplicación* / *Agregar a la pantalla de inicio*
- **iPhone (Safari):** Compartir → *Agregar a pantalla de inicio*

El **catálogo** (`index.html`) es solo web: no se instala como app.
